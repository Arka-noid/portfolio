# portfolio

Personal portfolio of Manuel Reza — optical systems engineer. An immersive single-page site (Vite + React, deployed on Vercel) presenting experience, projects, consulting services, and publications in photonics: system architecture, TRL maturation, FMCW LiDAR, and microwave photonics for space & defense. Includes deep-dive case-study pages for the space-radar beamformer and the solid-state FMCW LiDAR work.

```bash
npm install
npm run dev       # dev server
npm run build     # production build
npm run preview   # preview the build
```
